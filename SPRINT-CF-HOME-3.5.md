# CF-HOME-3.5 — Property Features Use Branching

## Purpose

Reveal follow-ups only for selected property features and uses.

## Implementation

Adds a concise property-feature and use selector whose follow-ups appear only for selected features, remain one level deep, and never declare eligibility.

## Files

- `assets/js/pvx-home-features.js`
- `CF_HOME_3_5_FEATURES_CONTRACT.json`

## Protected boundaries

- Existing Protection Score methodology and math remain unchanged.
- Personal discovery does not create policy findings or recommendations.
- Customer-reported facts remain distinct from verified facts.
- Quote readiness remains distinct from carrier eligibility.
- Consent, decision, and authorization states remain separate.

## Acceptance

- All roadmap feature choices are available with an exclusive None option.
- Only selected features create follow-ups.
- Feature branches remain one level deep and allow Not sure.
- No feature response creates an automated eligibility decision.
