# 408-CF-PVX-WEB-1.0 — Mapping Contract + Migration Boundary

CoverageFit v3.20.136 freezes the v3.20.135 SMS/PVX production candidate, introduces the authoritative native-web mapping contract, and defines the paired-repository migration boundary.

The mapping is fail-closed. Page and campaign context remain attribution only. Only an explicit customer selection may seed a discovery answer. Contact data never becomes permission, identity records are not silently merged, and discovery cannot create a Protection Score, eligibility conclusion, policy finding, recommendation, or binding authorization.

Allowed CoverageFit implementation areas are new web mapping/bootstrap/reconciliation/projection modules, PVX presentation and resume integration, the Snapshot checkpoint integration, route documentation, focused QA, and the explicitly authorized Home + Auto SMS classifier correction. Protected advisory math, report engines, RingCentral connection/webhook, consent/suppression, outbound gateway, producer takeover, and unrelated runtimes remain frozen.
