# 408-CF-PVX-HOOK-1.3 — SMS + AI Caller Return Hooks

Version: 3.20.168

Supported SMS continuations now promise the personal CoverageFit Snapshot, reuse compatible information and state that the journey begins with the first unanswered question. The secure handoff, single-use token, consent, suppression, retry, ownership and human-takeover engines are preserved.

AI-caller POST bootstraps accept only bounded discovery option values. Original customer wording remains evidence, channel context remains channel context, and `other`, ambiguous or explicit human requests remain producer-owned. No conversational handoff promises a policy finding, eligibility, price or response time.

The only protected runtime changes are two continuation-message literals documented in `CF_PVX_HOOK_1_3_PROTECTED_SMS_HASH_CHANGE.md`. The prior hashes remain in the Release 16 artifact history.
