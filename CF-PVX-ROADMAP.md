# CoverageFit Progressive Value Exchange Roadmap

Status: Active

Rollback baseline: `CoverageFit v3.20.83 / CF-ADV-1.12`

This roadmap supersedes the first-run six-chapter advisory orchestration while preserving the completed CF-ADV-1.1 through CF-ADV-1.12 intelligence. The legacy assessment is relocated to the optional current-policy review path; it is not deleted.

## Non-negotiable product sequence

**Personal discovery → discovery-only Snapshot → optional save/contact checkpoint → Home Profile and/or policy review → report revision → producer verification → recommendation → buy-in → decision.**

Early discovery creates only areas worth reviewing. Policy or quote evidence plus licensed producer judgment creates Dylan’s recommendation.

Semantic truth is explicit throughout: `advisoryReviewTopic` is not a `recommendation`; `topicResponse` is not `recommendationResponse`; customer-reported is not verified; quote readiness is not carrier eligibility; recommendation buy-in is not authorization; report saving is not contact consent; and personal discovery does not affect Protection Score.

## Sprint execution contract

Every sprint advances the patch version, reads the immediately preceding package, passes focused QA, preserves the exact v3.20.83 historical regression-failure set or reduces it, preserves protected hashes unless explicitly authorized, produces documentation and certification, packages a root-deployable ZIP, extracts and retests that ZIP, records `MASTER_PROGRESS_LEDGER.md`, and advances automatically. Major release endings additionally run the integrated journey gate and preserve a release production candidate.
